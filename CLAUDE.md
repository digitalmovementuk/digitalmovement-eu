# CLAUDE.md

## Messages & notes for Johnny (written as Raoul)

Goal: Johnny gets it in 5 seconds and can act without asking back. It should read like Raoul typed it on his phone, not like an AI report.

**Language & tone**
- German, "du", warm and direct. English only for short reactions ("Yes sure!", "FYI"), never full English updates.
- Start with "Brudi," / "Bruder," or go straight to the point. No "Hallo Johnny, ich hoffe ...".
- Delegate as a question: "Magst du ...?". Give ownership: "Du bist im Lead."
- End with thanks or an emoji, no sign-off: "Danke Brudi", ❤️, 🙏, :), 😅. Max 1-2 emojis.
- Plain words, no jargon. If something is technical, add the consequence: "Heißt: ..."
- Times in German time (Johnny is in DE). Deadlines as weekday + date: "bis Fr 28.11."

**Shape**
- Default 1-3 lines. One message = one topic.
- Every ask has: what + by when + link or repo path. Specific enough that "Was meinst du mit ...?" can't happen.
- Longer updates only as WhatsApp blocks (Johnny's own format):
  ```
  Hey Bruder, kurzer Stand zu [Thema] 👇

  *Erledigt*
  • ...
  *Als Nächstes*
  • ...
  *Von dir*
  • ... (bis Fr 28.11.)
  ```
- Meeting recap: one `*Thema*` block per topic, then `*To-dos*` with `Ich:` / `Du:` lines, then the repo path.
- WhatsApp formatting only: `*bold*`, `•`, `→`. No Markdown headers, tables or em dashes.

**Never**
- Passwords, API keys or 2FA codes in a message → "liegt im Passwort-Manager" / "frag mich kurz".
- File attachments → file goes in the repo, message gets the path.
- Recap what he already knows, explain reasons he didn't ask for, or list options when one recommendation will do.

**Examples**
- `Brudi, magst du [Kunde] um ein Trustpilot-Review bitten? Link: [...] 🙏`
- `[Kunde]-Seiten liegen im Repo unter [Pfad]. Kannst du sie bis Fr 28.11. in WP setzen?`
- `Mega!! Danke Brudi ❤️`
